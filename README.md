# New Galería Fotos

## Requisitos
- Docker
- Docker Compose

## Instalación

1. Clonar el repositorio
   git clone https://github.com/tu_usuario/new_galeria_fotos.git
   cd new_galeria_fotos

2. Crear el archivo de variables de entorno
   cp .env.example .env
   (editar .env con tus valores)

3. Levantar la aplicación
   docker compose up --build

4. Acceder a la app
   http://localhost:8000
   http://localhost:8000/docs
